# EtherWalletPro

EtherWalletPro: A highly secure, decentralized node-based service for real-time, multi-asset transaction processing and storage management.

The key benefits of using EtherWalletPro include:

- EtherWalletPro: A highly secure, decentralized
- node-based service for real-time, multi-asset
- transaction processing and storage management

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/EtherWalletPro.git`
2. `cd EtherWalletPro`
3. Install in editable mode: `pip install -e .`

## Configuration

EtherWalletPro is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
